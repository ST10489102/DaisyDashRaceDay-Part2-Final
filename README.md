# DaisyDashRaceDay - Part 2 - Final

Student: ST10489102

## What is this project?
This is a Web API for the Daisy Dash Race Day event. It manages categories, users and race results.

## How to run
1. Clone the repo
2. Open DaisyDashRaceDay.API in Visual Studio
3. Press F5
4. Swagger will open to test the API

## What was built
- CategoriesController - Add / View / Update / Delete categories
- UsersController - Register and view users  
- ResultsController - Save and view race results

## Technologies
- C# .NET 8.0
- ASP.NET Core Web API
- GitHub Actions for build

## Build Status
The project builds successfully. Check Actions tab for green check.
